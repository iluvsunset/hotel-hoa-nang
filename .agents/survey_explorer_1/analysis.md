## 7. Unicode, Encoding, and Web URL Safety Nuances

### A. macOS APFS NFD vs Standard NFC Normalization
On macOS file systems (APFS), Vietnamese folder and file names are stored using **NFD (Normalization Form Decomposed)**, while standard web browsers and Linux/HTTP servers expect **NFC (Normalization Form Composed)** or exact URI-encoded byte sequences.

- **Workspace Directory Name**: `Hotel Hoa Nắng`
  - Raw UTF-8 bytes: `48 6f 74 65 6c 20 48 6f 61 20 4e 61 cc 86 cc 81 6e 67` (Decomposed combining diacritics: `a` + `\u0306` + `\u0301`)
- **Hotel Gallery Directory Name**: `Ảnh Khách Sạn`
  - Raw UTF-8 bytes: `e1 ba a2 6e 68 20 4b 68 c3 a1 63 68 20 53 e1 ba a1 6e` (Precomposed NFC in folder name on disk)
- **Room 207 Video File Name**: `clip quay phòng có ban công.mp4`
